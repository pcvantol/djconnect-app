# Native VibeScape control qualification

The disposable host mounts the actual VibeScapeScreen, AppModel and existing
Session character control. URLProtocol intercepts every HTTP request. Producer
fixtures supply synthetic owner/runtime/catalogue data; explicitly marked routes
supply synthetic persona confirmations and opaque occurrence leases. It never
pairs, contacts HA/provider/model services, plays audio or accepts microphone
permission. The host follows mode dismissal rather than leaving a ghost screen.

Generate with an external destination, pinned JOSESwift checkout, `--platform iOS`
and a fresh `--bundle-suffix`. Run NativeVibeScapeControl serially on an owned,
temporary iPhone/iPad simulator, with external derived/result paths and
`-collect-test-diagnostics never`. Every app launch includes `--uitesting`.
Never reset an ordinary app's permission database or preferences.

The accepted-world case taps the real character choices, waits for confirmed
Session state and the real Screen's accessible world value, then captures native
Metal-backed screenshots for all four families. The rejected-save fixture returns
a revision conflict and requires the currently confirmed Home world to remain.
The same production source/revision reducers have stale/ABA/owner/background
regressions in the Swift tests.

Other cases exercise background/owner withdrawal, actual microphone denial,
freshly loaded visual help, and Dynamics/reset access in five languages with
large text. The Reduce Motion case turns on the real setting through the Settings
app **on that disposable simulator**, then requires the app's actual system
status to report enabled. Presence of a launch argument is not evidence.

Status counters distinguish context/revoke POSTs (source reads/retirement) from
mutations. Ordinary controls/permission/help must cause no settings, interpreted
visual command or Ask DJ POST. Accepted character changes cause exactly the
explicitly requested persona writes. Slider gestures do not trigger server calls.

This covers shared native components with synthetic server/source fixtures.
It is not authorized microphone/STT/directive acceptance, a fully paired Root,
physical iPhone/iPad GPU/energy, real VoiceOver navigation, real Spotify playback
or provider acceptance. Native Mac offscreen shader proof is separate in
`../vibescape/`; macOS target compilation and its actual NSSlider pointer test
are also reported separately.
