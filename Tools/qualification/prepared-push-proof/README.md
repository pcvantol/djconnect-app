# Private prepared-proof parser preparation

This directory is uncomposed SDK-independent source. Nothing imports it into the shipping package, project, widget or Activity. It performs no network, key, App Attest, token, Activity, Keychain, provider or HA operation. It does not construct consent, an original clock witness or an authenticated Core/API admission. The existing shipping positive factory stays closed.

The fixture manifest pins the exact private Core R9 / API v2 / nested-shape R2 proposals. These are preparation inputs, not a normative accepted contract. The three original synthetic, expired byte/hash controls and original 21 negative and eight causal Activity expectations are preserved byte-for-byte. No raw private review/audit is published. The old multi-invalid Mac examples remain historical; three separate iOS Activity positives and only-client-type Mac mutations provide causal controls. Two prospective/native identity mismatches are separately rejected semantically, although their JSON shapes are valid.

`PreparedPushProof.swift` checks the original response limit (8192 bytes), decoded transcript limit (4096 bytes), strict padded standard Base64 and unused bits, raw lexical JSON before dictionaries, exact closed outer/inner/nested keys, original known client fields, domain mapping and both hashes. Its canonical-byte check compares the original bytes; it never replaces them for hashing. API-only policy/owner bindings are opaque correlation data. A first canonical API job is not independently preknown to the client: inner/outer equality pins it only in the original model flow. This equality is not admission or an SDK signing right. Later job/policy changes are rejected. Reuse references and target identity/token hashes remain bound to their original phase.

`ModelFlow` uses **synthetic integer ticks**, not native clock acquisition or cross-domain mapping. It models one consumption per phase, an explicit synthetic key-verification observation before target preparation, irreversible observed context loss, loss of a reply, deadlines, backwards ticks and rejection. Its positive records cannot activate production. Tests do not verify Apple cryptography, actual owner authentication, key counters/CAS, native provisioning or provider delivery.

Run `python3 Tools/qualification/prepared-push-proof/run_preflight.py NEW_EXTERNAL_DIRECTORY`. The directory must not exist and must be under `/Volumes/Shared Data/tmp/pcvantol/`. The runner compiles Swift 6 with the exact existing strict lexical source plus an isolated error shim, writes original compile/run exits and logs, and binds before/after hashes. The API's historical expected classifications are not treated as proof: actual Swift outcomes are recorded independently.

Actual operator/current-owner admission, qualified original Core/API clock mapping, full native verifier/provisioning and real WidgetKit/ActivityKit/APNs delivery remain open. Parser success cannot open those gates.
