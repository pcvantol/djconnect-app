# DJConnect App development extension

`djconnect-app` owns Apple client implementation and presentation for iOS, iPadOS, macOS and watchOS. DJConnect remains the product-authority for cross-component architecture and roadmap.

Use `docs/ARCHITECTURE.md`, `docs/DEVELOPMENT.md`, `docs/BUILD_RELEASE_HYGIENE.md`, `Package.swift`, and the existing Apple CI workflows for local build, test and release work. Existing Trusted Delivery evidence remains authoritative.
