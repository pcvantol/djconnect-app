# Session/Moment artwork consumer adoption

DJC-APPLE-SESSION-MOMENT-ARTWORK-V1-20261014; parent Core artwork slice.
Local design only. Producer remains selected/queued; no invented wire schema.

Use the existing normal Session timeline for active contributions and archives.
Do not restore the removed legacy Sessieverloop screen or its detail sheets.
The current Moment, compact observed-playback entry, rich contribution and safe
archive/search context need one typed subject-bound representation and renderer.
The producer must bind exact media/version, Session/Moment/entry, media revision,
source attribution, display/crop policy and live/history/retention rights.

Before implementation, obtain the exact schema, real transport fixtures, permitted
image assets, checksums and producer source pin. Native rendering alone cannot
mint a grant. Current playback A/B, Discovery and Forecast image rights cannot be
borrowed for a Moment or historical entry.

One bounded loader must fence owner, source, subject/revision and original
expiry before and after asynchronous work. Revoke URL and decoded pixels on
withdrawal; late completion cannot restore them. Missing/expired data leaves a
compact text fallback without moving the conversation, disabling controls or
creating another turn. Keep attribution and the context-question button visible.

Older entries use only a separately qualified Core resolution by exact stored
identity, coordinated for visible/nearby rows. Ordinary history/search/open reads
remain pure. No title match, client Spotify/weblookup, N+1 model calls, bulk
backfill, new opt-in or private Discovery grant reuse.

Acceptance: correct cover; actual artist photo for subject A while B plays;
qualified historical re-resolution; then wrong owner, insufficient identity,
expiry/revocation, track switch/late response, missing image and provider failure.
Verify five languages, accessibility, stable geometry, context/actions and scroll.
Core live, Core history, native renderer, joint chain and installed/provider
acceptance remain separate. Do not claim whole-slice DONE from fallbacks or fixtures.
