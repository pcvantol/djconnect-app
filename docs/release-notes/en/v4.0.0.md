# DJConnect App 4.0.0 RC 1

## Build 40475

- Centered pairing and permission dialogs, with full-screen Track Insight sharing.
- Improved Watch demo synchronization, navigation and playback controls.
- Four Watch games with tap and Digital Crown controls via More > Games.

## Build 40474

- Consistent frosted buttons, pairing and onboarding on iPhone, iPad and Mac.
- Watch demo playback, favorites, speakers and questions synchronize with iPhone.
- Watch VibeScape dynamics use the Digital Crown; Watch logs are viewed separately on iPhone.

## Changed

- This internal release candidate moves the iPhone, iPad, and Apple Watch
  clients to the shared DJConnect 4.0 compatibility line.
- The private-device deployment route now validates the dedicated Platform 4.0
  operational manifest before it installs an approved build.


- Prepare VibeCast TV QR linking with JOSESwift 3.0.0 encryption and bundled Apache 2.0 notices. Secure handoff is still in development.
