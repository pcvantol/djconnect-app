# Archived Session scroll preparation

Source audit found the render cache rebuilt a dictionary/result array on every snapshot, even with unchanged input; the screen asks for snapshots both outside and inside its retention TimelineView. Reuse the prepared snapshot while input/session/epoch are unchanged and the wall clock remains in the original retention/artwork-deadline window. Changed input and exact expiry bypass reuse. Clear resets all preparation. The extra input/snapshot copy is stored only when every source row remains retained, so removed/expired rows are not kept there. Existing server retention/admission checks remain authoritative.

Archived rows now appear immediately instead of creating a fade animation/state update as each lazy row mounts. Live Flow retains its fade. Visibility callbacks only replace their visible-ID set/prefetch window when IDs actually change and avoid redundant header/tail state assignments. Artwork prefetch follows visibility/deadline/availability and once when scrolling settles, rather than each scrolling phase transition. Existing scoped lazy loading, active controls, search and native material remain.

Added unrun regression source for unchanged-input snapshot expiry, removal and epoch replacement; existing same-identity withdrawal and stable-row tests remain. Diff/work-register validation only. No build, compiled test, profiling, installation or measured FPS claim under explicit-build-only instruction. Pending PR179; installed40447 unchanged.
